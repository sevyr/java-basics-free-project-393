# Генератор и проверка надёжности паролей

Консольное приложение на Java для генерации псевдослучайных паролей с настраиваемым набором символов и оценки их сложности.

## Возможности
* **Генерация паролей (`generatePassword`)**: создание воспроизводимого пароля заданной длины по ключу (`seed`) с возможностью включать прописные буквы, цифры и спецсимволы (`!@#$%^&*`).
* **Оценка надёжности (`checkPassword`)**: проверка пароля по 5 критериям (длина от 8 символов, строчные, прописные буквы, цифры, спецсимволы) с выдачей итогового вердикта.

## Как запустить

Скомпилируйте и запустите проект из корневой директории:

```bash
javac *.java && java Main
```

### Пример вывода

```text
== Генерация паролей ==
буквы и цифры:    5vjehYzZEzZ0
со спецсимволами: p0B!7#nL2@vX9\$kR

== Проверка надёжности ==
abc        -> Слабый пароль (оценка 1 из 5)
abcdef1234 -> Средний пароль (оценка 3 из 5)
Abcdef123! -> Очень надёжный пароль (оценка 5 из 5)
